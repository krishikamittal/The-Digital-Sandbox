# KRISHIKA.exe — Digital Sandbox

A playful interactive personal portfolio built as a small pixel-style digital world.

Instead of presenting my portfolio as a traditional webpage, I designed it as an interactive space where visitors can explore my profile, projects and skills.

## ✨ Features

* Interactive pixel-style personal world
* Playable character movement using keyboard controls
* Collectible hidden coins
* Interactive NPC chatbot
* Quest system for exploring the portfolio
* Interactive project cards
* Day/night interaction
* LinkedIn and GitHub links
* Responsive layout for different screen sizes

## 🎮 How to Explore

### Move

Use **WASD** or the **arrow keys** to move around the world.

### Collect

Click the hidden coins to collect them.

### Explore

Interact with objects and project items to discover different parts of the portfolio.

### Talk to Krish

The NPC chatbot can answer simple questions such as:

* `who are you?`
* `skills`
* `projects`
* `what are you learning?`

### Quests

**QUEST 01 — EXPLORE**
Inspect the three project items.

**QUEST 02 — COLLECT**
Find every hidden coin.

**QUEST 03 — CONNECT**
Open the social links and say hi.

## 🎨 Design

The website combines:

* Pixel-inspired game visuals
* Retro computer aesthetics
* Playful UI elements
* Interactive storytelling
* Personal portfolio content

The goal was to make the portfolio feel more like a small world to explore rather than a conventional resume website.

## 📱 Responsiveness

The interface is designed to adapt to desktop and smaller screen sizes while preserving the main interactive experience.

## 🚀 Running Locally

No installation or build process is required.

Simply open `index.html` in a browser.
